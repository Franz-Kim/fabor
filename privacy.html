개인정보처리방침

적용 대상: Agent Team Chat (FABOR 내부 업무용 앱) · 시행일: 2026년 11월 8일

FABOR(이하 "파보르")는 내부 업무용 앱 Agent Team Chat(이하 "앱")에서 Google 계정 정보를 다음과 같이 처리합니다. 앱은 파보르 대표가 자신의 업무를 정리하기 위해 사용하며, 일반 이용자에게 제공하지 않습니다.

1. 처리하는 정보

  • Gmail(읽기): 메일 제목, 보낸 사람, 날짜, 본문 일부. 확인할 메일을 요약하고 답장 초안을 만드는 데 사용합니다.
  • Gmail(초안 작성): 사용자가 요청한 답장 초안을 Gmail 임시보관함에 저장합니다. 앱은 메일을 발송하지 않습니다.
  • Google Calendar(읽기): 일정 제목, 시간, 장소. 오늘부터 7일간의 일정 브리핑에 사용합니다.
  • 계정 정보: 연결된 Google 계정의 이메일 주소.

2. 이용 목적

위 정보는 사용자 본인에게 일정·메일 브리핑을 보여 주고, 사용자가 요청한 답장 초안을 만드는 목적으로만 사용합니다. 광고, 판매, 신용 평가, 사용자 프로필 작성에는 사용하지 않습니다.

3. 보관과 보호

  • Google 인증 토큰과 앱 대화 기록은 파보르가 관리하는 Mac 한 대의 로컬 디스크에만 저장하며, 파일 권한으로 접근을 제한합니다.
  • 앱은 사설 네트워크(Tailscale)에 연결된 파보르 기기에서만 접속할 수 있습니다.
  • 메일·일정 원문은 별도 데이터베이스에 복사해 두지 않습니다. 사용자가 요청한 답변과 브리핑에 포함된 요약만 앱 대화 기록에 남습니다.

4. 제3자 제공 및 처리 위탁

요약과 초안 작성을 위해, 사용자가 요청한 범위의 메일·일정 내용을 AI 모델 제공자(OpenAI)의 API로 전송해 처리합니다. 그 밖의 제3자에게는 제공하거나 판매하지 않습니다.

5. Google API 서비스 사용자 데이터 정책 준수

Agent Team Chat's use and transfer of information received from Google APIs to any other app will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

앱이 Google API로 받은 정보를 사용하고 전송하는 방식은 제한적 사용 요구사항을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다.

6. 보유 기간과 삭제

  • 앱 설정 화면에서 Google 연결을 해제하면 저장된 인증 토큰을 즉시 삭제합니다.
  • Google 계정의 서드파티 액세스 관리에서 언제든 앱의 접근 권한을 철회할 수 있습니다.
  • 앱 대화 기록의 삭제를 원하시면 아래 연락처로 요청해 주세요.
